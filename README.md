# Прототип Интернет-магазина

## 1. Описание проекта 

Прототип интернет-магазина электроники с возможностью:
- Регистрации и авторизации пользователей (JWT)
- Просмотра каталога товаров с иерархической структурой категорий
- Добавления товаров в корзину и оформления заказов
- Оставления отзывов с оценками и фотографиями
- Фильтрации товаров по характеристикам
- Администрирования каталога (роли USER/ADMIN)

СУБД: PostgreSQL 15+
ORM: JPA (Hibernate)
Бэкенд: Java 8+ / Spring 5+
